# 🛒 CartNest

A modern Full Stack E-Commerce Web Application built using HTML, CSS, JavaScript, Node.js, Express.js and MySQL.

---

## 🚀 Features

### 👤 User Module
- User Registration & Login
- Browse Products
- Search Products
- Category-wise Filtering
- Add to Cart
- Wishlist Management
- Place Orders
- Order History

### 🔐 Admin Module
- Admin Login
- Dashboard
- Add Products
- Edit Products
- Delete Products
- Manage Orders
- Manage Categories
- Manage Users

---

## 🛠️ Tech Stack

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js

- MySQL

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/anjaliKatheriya/CartNest.git
```

2. Install dependencies

```bash
npm install
```

3. Start the server

```bash
npm run dev
```

4. Open in browser

```
http://localhost:5000
```
